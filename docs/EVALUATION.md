# Оценка: когорта, сплиты, as-of, метрики

Каркас `src/d2intel/evaluation/` — ядро проекта. Он не считает признаки и не
обучает модели: он задаёт правила, по которым любая метрика будет честной.

## 1. Target и когорта

Target — `P(Team A выигрывает карту 1 | карта сыграна)`.

**Team A фиксируется канонической идентичностью, а не стороной**: из двух
участников Team A — тот, чей `team_id` меньше. Правило детерминировано и не
зависит от Radiant/Dire.

В когорту входят карты с `map_number = 1`, `result_type = 'played'`, известным
победителем и двумя различными командами (`cohort.py`). Технические результаты
(forfeit/walkover/void) не идут в обучение — это отдельные статусы.

## 2. As-of и cutoff

Ни один признак не может использовать данные, недоступные на cutoff
(`asof.py`). Две шкалы:

| Шкала | Смысл | Когда |
|---|---|---|
| `EVENT_TIME` | факт известен, когда событие произошло | ретроспективный срез |
| `AVAILABLE_AT` | факт известен, когда мы его получили | настоящий pre-match прогон |

**Известное ограничение.** Истинный cutoff «до драфта» требует времени
объявления фикстуры, которого OpenDota не даёт. Ретроспективно считается
известным всё, что произошло строго раньше `event_time` матча. Это **не**
консервативная оценка, и она должна быть указана в любом отчёте о метрике.

## 3. Сплиты

Только по времени, без перемешивания (`split.py`):

- train / valid / test — последовательные интервалы `event_time`;
- между ними — **embargo** (по умолчанию 24 часа), наблюдения в разрыве
  исключаются;
- серия не должна расщепляться между сегментами — проверяется
  `assert_groups_do_not_straddle`;
- при слишком короткой выборке фолды не строятся вовсе.

## 4. Метрики и честность (`metrics.py`)

- `accuracy`, `log_loss` (вероятности обрезаются — нет бесконечности);
- `majority_class_accuracy` — **нижний ориентир**: точность константного
  прогноза. Метрика модели ниже него означает, что модель ничего не добавила;
- неопределённость — **grouped bootstrap по сериям** (зависимость внутри серии);
- при `n < 30` вердикт **insufficient evidence**, заявлений о значимости нет.

## 5. Факты по текущему срезу (2026-09-22)

Прогон `scripts/build_game1_cohort.py`:

| Показатель | Значение |
|---|---|
| Карт в когорте game1 | 162 |
| Серий / команд | 162 / 147 |
| Диапазон | 2026-07-29 … 2026-09-22 |
| Баланс меток (доля побед Team A) | 0.531 |
| **Точность константного прогноза** | **0.531** |
| train / valid / test / исключено | 130 / 15 / 13 / 4 |
| Вердикт по test-сегменту | insufficient evidence (13 < 30) |

Вывод: нижний ориентир — **53.1%**, и test-сегмент содержит 13 наблюдений.
Никакое заявление о точности модели на этом объёме невозможно; чтобы получить
осмысленную оценку, когорту нужно расширить (см. «Дальше»).
