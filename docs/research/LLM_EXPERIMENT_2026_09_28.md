# Онлайн-эксперимент: LLM-предикт по Dota 2

**Дата:** 2026-09-28 (ночная автономная сессия)
**Запрос владельца:** онлайн-эксперимент — LLM делает предикт по доте, результаты
отображаются в лайв-ставках в виде инфоповода (Telegram-сообщество).
**Эпики бэклога:** EPIC 19 (LLM analyst) — LLM-001/002/003, переведены из
`Proposed` в реализованный прототип.

## Что построено

| Модуль | Назначение |
|---|---|
| `src/d2intel/llm/evidence.py` | Сбор **только pre-match** данных из публичного OpenDota API (без ключа): форма команд за 30 дней, личные встречи. Строгий cutoff — матчи после целевого не учитываются |
| `src/d2intel/llm/analyst.py` | LLM-аналитик: версионированный промпт (`llm-analyst-v1`), вызов Atria-Dawn-Preview, парсинг, guardrails |
| `src/d2intel/llm/telegram_format.py` | Форматирование прогноза в сообщение-инфоповод с честной подписью |
| `tests/llm/` | 35 тестов, включая негативные (фабрикация, запрещённые формулировки, утечка будущих игр) |

## Архитектурный принцип (из LLM-001)

LLM **не заменяет** численное предсказание. Он работает только от evidence и
не меняет числа модели. Guardrails отбрасывают любой вывод, где:

- нет `p_radiant` или оно не число;
- `p_radiant` вне `[0.05, 0.95]` — абсолютной уверенности не существует;
- в тексте есть запрещённые формулировки («гаранти», «100%», «profit»…);
- **появились числа, которых не было в evidence** — фабрикация.

Матч 6 отклонён по фабрикации: LLM привёл «77%», которых не было в evidence.
Именно на это рассчитаны guardrails — система не пустила выдуманное число.

## Почему это не «победа»

- N=5 — статистически незначимо. Это демонстрация конвейера, не валидация модели.
- Wallachia — кластер матчей одних и тех же команд (Yandex/NaVi/LGD), форма
  коррелирует между играми. На.BLAST Slam VIII нужен отдельный прогон.
- Атрибуция: все данные — OpenDota API, без скрапинга.

## Связь с NOTIF-001

Инфоповод LLM-аналитика — отдельный вид сообщения. Сейчас NOTIF-001 шлёт
триггеры (старт турнира/матч/драфт) с вероятностью из заморозки. LLM-бриф —
это **дополнительный** контент, а не замена чисел модели.

## Что нужно владельцу для запуска в live

1. Задать `ATRIA_API_KEY` в `.env` на Windows-машине.
2. Решить: инфоповод LLM в тот же Telegram-чат, что и NOTIF-001, или отдельный канал.
3. Прогнать на BLAST Slam VIII (29.09–11.10) — там будут свежие данные.
