# SRC-003 — Результаты пробы: OpenDota live + Liquipedia parse (расписание)

**Дата:** 2026-09-27 (ночь перед Wallachia S9). **Инициатор:** владелец (находки на
реальных данных: live-игра BB Streamers Battle 15, Rostik vs avice).
**Статус:** проба выполнена интеграцией с этой машины; это промежуточный отчёт к
будущему ADR-008, НЕ вердикт.

## Что проверено с этой машины (2026-09-27 ~02:30 +03)

| Проба | Результат |
|---|---|
| `api.opendota.com/api/live` | **PASS** — 100 живых игр; поля `league_id`, `series_id`, `activate_time`, `game_time`, `delay` на месте (подтверждает находку владельца) |
| Liquipedia `action=cargoquery` | **FAIL** — «Unrecognized value for parameter "action"»: Cargo API наружу не выставлен. Подтверждает SRC-002 |
| Liquipedia `action=parse&page=…&prop=wikitext` | **PASS (механизм)** — 200 и wikitext для существующих страниц; титул Wallachia S9 не угадан за 5 вариантов (см. открытый вопрос) |
| Liquipedia rate limit | соблюдался (1 запрос / 2 c); UA обязателен |

## Ключевые выводы владельца (приняты в архитектуру)

1. **Склейка по ID, не по именам**: Liquipedia отдаёт серию (Bo3/Bo5), OpenDota — игры;
   join по `league_id` + временное окно, `series_id` — ключ группировки. Наши
   канонические `series_key` = `series:<opendota series_id>` — **то же пространство
   идентификаторов**, схема БД уже поддерживает склейку без миграций.
2. **Стороны меняются** между картами Bo3 (Radiant/Dire) — сопоставление по названиям
   команд сломалось бы; по ID не ломается.
3. **Условная частота опроса**: расписание — кэш 6–12 ч + ручное обновление;
   live-поллинг (раз в минуту) — только пока есть живая игра.

## Открытый вопрос (блокер парсера)

Точный титул страницы Wallachia S9 на Liquipedia: варианты
`PGL/Wallachia/2026/Season 9` и др. — missingtitle. Владельцу, у которого проба
вернула реальные матчи (BB Streamers Battle 15), — прислать URL страницы; парсер
принимает титул как параметр, угадывание не понадобится. Возможен fallback: поиск по
`action=query&list=search` + ручное подтверждение.

## Правила интеграции (для ADR-008, Proposed)

- Liquipedia — источник **только для отображения расписания** (display-only);
  в critical path модели не входит — вердикт SRC-002 для модели остаётся в силе.
- Attribution CC-BY-SA 3.0 обязателен рядом с данными; UA вида
  `d2intel/0.1 (contact)`; интервал ≥2 c между запросами; кэш 6–12 ч.
- Fallback сохраняется: при недоступности Liquipedia расписание ведётся вручную
  (миграция 0004, `scheduled_match`) — оба пути в одном UI.
- Live-драфт (OpenDota `/live` → `series_id` → драфт конкретной игры) — вторая
  фаза, «бонус когда идёт игра»; для Gate-2-данных достаточно кнопки «Внести
  драфт» вручную.

## Следующие шаги

1. От владельца: URL страницы Liquipedia (Wallachia S9) → парсер wikitext
   ({{Match2}}-шаблоны: команды, время, BoX) + кэш + UI-блок с attribution.
2. ADR-008 с вердиктом по правилам выше.
3. Live-фаза (опционально): `/api/live` → группировка по `series_id` → показ
   идущих игр и драфта.
