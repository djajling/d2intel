# ADR-009 (черновик): blast.tv как фолбэк-источник live-драфта

**Статус:** черновик — решение владельца.
**Дата:** 2026-09-27.
**Контекст:** ADR-008 определил live-наблюдение (OpenDota `/live` как основной
путь, STRATZ как приоритет 1 по квоте). Цель этого ADR — фолбэк на случай,
когда оба не дают драфт: OpenDota у части турнирных лобби отдаёт
`players: []`, STRATZ ограничен квотой free-tier (~2 запроса / 15 минут).

## Данные пробы (2026-09-27, bounded-проба без Playwright)

* `GET https://blast.tv/matches` → **404** (страницы с таким путём нет).
* `GET https://blast.tv/` → **200**, ~18 КБ, обычный curl с обычным UA —
  Cloudflare-блока из прошлого опыта нет. Есть раздел `/dota`.
* Сетка pick/ban наblast.tv содержит 24 слота (12 на команду: 5 пиков +
  7 банов), разнесённые по radiant/dire — но по прошлым наблюдениям на
  лайв-играх она часто пустая и подставляется постфактум.

## Что нужно проверить до принятия (не сделано)

1. Страница конкретного матча: где живёт драфт (HTML / JSON в `__NEXT_DATA__`
   / XHR-эндпоинт) — это определяет стабильность парсера.
2. Задержка появления сетки относительно стадии пиков — по прошлому опыту
   она существенна; фолбэк имеет смысл только если задержка < конца пика.
3. Лegal/этическая сторона: у blast.tv нет открытой лицензии — для личного
   инструмента приемлемо, для публичного лендинга — нет (в отличие от
   Liquipedia CC-BY-SA).

## Архитектурное место фолбэка

```
STRATZ (квота ок)  →  OpenDota /live  →  blast.tv фолбэк  →  «нет данных»
```

* Включается только когда оба основных пути не отдали драфт — не как
  параллельный поллинг (лишний трафик чужому сайту не нужен).
* Реализация через Playwright, не requests: по прошлым пробам часть
  страниц рендерится JS-ом; curl-проба выше показывает, что статический
  HTML доступен, но с сеткой драфта это не проверено.
* Дедупликация: хэш последнего состояния драфта на матч, событие — только
  при изменении (иначе UI-поллинг умножит трафик).

## Альтернативы

* **Ничего не делать** — текущего покрития достаточно для личного
  инструмента: OpenDota отдаёт пики в реальном времени, STRATZ добавляет
  баны по квоте, полный драфт с банами появляется в доигранной карте.
* **Liquipedia match ticker** — уже используется для расписания; live-драфт
  там не появляется, дубль не нужен.

## Рекомендация

Отложить принятие: у владельца нет requests на фолбэк, а ценность
появляется только в окне live-матча STRATZ-квоты + пустых лобби OpenDota
одновременно. Вернуться, если за Wallachia S9 такое окно реально случится.
