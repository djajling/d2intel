# Подключение нового агента

Контекст уже находится в Git, копировать прошлый чат или большой промпт не нужно.

1. Открыть репозиторий `djajling/d2intel`, проверить ветку, рабочее дерево и свежий `origin/main`.
2. Прочитать [AGENTS.md](../../AGENTS.md) и [HANDOFF_PROMPT.md](../../HANDOFF_PROMPT.md).
3. Для назначенной задачи прочитать карточку в `BACKLOG.md`, связанные ADR, код и тесты. Не начинать автоматически `FEAT-001` и не выполнять повторно завершённые `INF-001`/`ING-001`.
4. Следовать [REPO_SETUP.md](../../REPO_SETUP.md): проверки → обновлённая передача → согласованный commit/push → локальный запуск/обновление → health-проверка. Отсутствие доступа к компьютеру владельца явно фиксировать как блокер деплоя.
5. Перед окончанием работы обновить существующий handoff: результат, ограничения, тесты, runtime и следующий шаг. Не требовать от владельца переносить контекст вручную.

Для агентов, не читающих `AGENTS.md` автоматически, достаточно указать: «Прочитай AGENTS.md в корне репозитория и актуальную передачу». Сам факт подключения к Git не гарантирует, что конкретный инструмент автоматически прочтёт инструкции.
