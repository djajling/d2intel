# Промпт для запуска агента (копируй целиком)

Это текст, который ты отправляешь другому агенту после того, как он подключён к GitHub и к репозиторию `djajling/d2intel`.

---

Прочитай файл `AGENT_INF001.md` в корне репозитория `djajling/d2intel` (ветка `main`).

Выполни задачу **INF-001** строго по этой инструкции, без отклонений:

- Инструкция в файле — единственный источник истины по задаче. Дополнительно прочитай `ARCHITECTURE.md` (§2 и §7), `FIRST_10_TASKS.md`, `REPO_SETUP.md` и карточку `INF-001` в `BACKLOG.md`.
- Рабочий язык — русский.
- Работай в ветке `task/INF-001`, коммиты по соглашениям из `REPO_SETUP.md` (`INF-001: ...`).
- Если что-то неоднозначно — **не угадывай**. STOP, опиши вопрос и жди решения. Архитектурные решения не принимай.
- Строго соблюдай раздел «Категорически НЕ делать»: не создавай доменную логику, не пиши миграции схемы БД, не создавай пустые Future-каталоги (`experts/`, `live/`, `market/`, `backtest/`, `frontend/`), не трогай временную семантику (cutoff, as-of, snapshots).
- Не меняй существующую документацию (`ARCHITECTURE.md`, `PRODUCT.md`, `BACKLOG.md`, `FIRST_10_TASKS.md`, ADR).

По завершении верни отчёт в формате из раздела «Формат возврата»: список файлов, вывод зелёного `pytest`, зафиксированные версии зависимостей, что не сделано и почему, список STOP-вопросов, команды для локального запуска.

## Вариант без файла в репозитории

Если файл `AGENT_INF001.md` ещё не загружен, используй `HANDOFF_INF001_PROMPT.md` — это тот же текст, самодостаточный, его можно вставить прямо в сообщение агенту.
