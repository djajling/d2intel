## Прогон v3 (2026-09-26, PATCH-002): патч-веса и d_team_same_patch_n

Manifest ревизия 3: 10 признаков (+`d_team_same_patch_n`), затухание весов по
патч-расстоянию (`patch-weight.v2`, сетка decay 0.6/0.75/0.9, выбор на valid
LR-гридом, test не читается).

- **Выбор decay: различий на valid нет** — log_loss 0.70429 (0.6) / 0.70433
  (0.75) / 0.70433 (0.9). Выбран 0.6, но разница в 5-м знаке: патч-веса на
  текущих данных для LR практически нематериальны (recency-веса с half-life
  120 дней уже поглощают большую часть патч-эффекта).
- Frozen test v2 (n=140): **LR (10 признаков) 0.5714 / log_loss 0.6878**;
  CatBoost 0.5429 / 0.6913. Парная разница CI95 [−0.013, +0.021] — значимого
  преимущества нет. Порог 0.70 не достигнут.
- Итог: accuracy LR подросла (0.5571 → 0.5714), log_loss чуть хуже (0.6826 →
  0.6878) — в пределах шума при n=140. Champion не меняется. CatBoost снова
  проиграл.
- Известный край (зафиксирован): run_key по умолчанию производен от хэша
  сплита — повторный прогон на том же сплите столкнулся с v2-регистрацией
  (идемпотентность вернула старую версию, снимки дедуплицировались — БД
  чистая, 140 записей). Регистрация проигравшего v3-варианта не выполнялась;
  для будущих прогонов передавать `--run-key` явно.

## Вердикт

- **Порог 0.70 не достигнут** (0.55) — по правилу ADR-007 фиксируется честно,
  модели не подгонялись; при n=140 CI точности ±8 пп.
- **Champion остаётся LR** (рекомендация исполнителя): challenger не показал
  значимого улучшения ни по одной метрике; формальное решение о промо — за
  владельцем (G-MODEL).
- Осмысленного сигнала от CatBoost на текущем признаковом наборе нет — это
  ожидаемо: 9 дифференциалов формы, где деревьям нечего выиграть у линейной
  модели. Реальный шанс challenger'а — после расширения признаков
  (PATCH-002/TEAM-002, hero pool) и роста покрытия player-данных.
